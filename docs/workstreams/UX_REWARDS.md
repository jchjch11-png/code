# UX·스티커 보상 업무지침

- 담당은 Sol UX·보상이다. 화면 흐름, 반응형 레이아웃, 접근성, 보상 상태 표현과 스티커 자산 명세를 맡는다.
- 수용 기준은 [제품 요구사항](../PRODUCT.md)과 [저장소 지침](../../AGENTS.md)을 따른다. 제품 규칙 변경은 메인과 합의한다.
- 현재 S0의 범위는 이 지침의 작성과 검토다. 이후 단계의 화면, 이미지, 코드는 계획이며 후속 개발 지시에 맞춰 착수한다.
- 첫 버전은 로그인 없이 기기 안에 프로필, 설정, 섭취 기록, 스티커 위치를 저장하는 기본안으로 설계한다.

## 다섯 화면과 이동

### 초기설정

- 첫 화면에서 앱 언어를 바꿀 수 있게 한다. 현재 언어와 언어의 자칭 표기를 사용해 초기 화면을 읽기 어려워도 선택할 수 있게 한다.
- 몸무게, 성별, 나이, 활동량을 입력하는 흐름과 직접 목표를 입력하는 흐름을 설계한다. 입력이 필요한 이유와 단위를 각 항목에서 확인할 수 있게 한다.
- 권장량의 근거를 설명하고 변경 가능한 음용 목표로 표시한다. 처방된 목표가 있다면 직접 입력할 수 있게 한다.
- 목표 확인 후 알림 설정으로 이어지는 선택지를 제공한다. 알림을 건너뛴 사용자도 오늘 화면에서 기록할 수 있게 한다.

### 오늘

- 물이 차오르는 컵 또는 캐릭터를 중심에 배치하고 현재량, 목표량, 남은 양, 달성률을 숫자와 텍스트로 함께 표시한다.
- 채움은 목표에서 가득 찬 모습으로 유지한다. 초과량은 실제 기록과 달성률에 반영하고 남은 양은 0으로 표시한다.
- 자주 쓰는 컵 용량을 한 번에 기록하고 직접 입력으로 이어지는 동작을 가까이 둔다. 모든 빠른 입력에 실제 용량을 표시한다.
- 저장한 양을 화면에 즉시 알리고, 입력 직후 취소와 기록 목록에서의 수정·삭제를 제공한다. 저장이 실패하면 입력을 보존하고 다시 시도할 수 있게 한다.
- 자동 입력과 직접 입력의 결과를 목록에서 같은 방식으로 확인하고 수정하게 한다. 보상 구간이 바뀌면 당일 카드에 변경을 표시한다.

### 알림설정

- 자동 배치와 개별 시간 설정을 제공한다. 기상·취침, 조용한 시간, 회당 용량과 예상 알림 일정을 설정 중에 확인할 수 있게 한다.
- 목표를 회당 용량으로 나누고 나머지가 있는 경우 마지막 예정량을 일정 미리보기에서 확인할 수 있게 한다.
- 알림의 예정량 100%·50% 기록 동작에 실제 mL를 함께 표시한다. 표시 자릿수와 액션 길이는 OS 시제품에서 확인한다.
- 미루기, 건너뛰기, 목표 달성 후 당일 알림 중단을 이해할 수 있게 표시한다. 놓친 양의 몰아 마시기를 유도하는 표현은 피한다.
- 권한 거부나 시스템 제한 상태에서는 현재 상태와 이용 가능한 설정 경로를 안내한다. OS별 액션 노출과 앱 복귀 흐름은 네이티브 담당과 합의한다.

### 달력

- 월별 달력과 선택한 날짜의 섭취량·달성률·획득 스티커를 함께 제공한다. 날짜 칸이 좁을 때 세부 정보는 날짜를 선택해 읽는다.
- 날짜 상세에서 해당 날짜의 스티커를 골라 같은 날짜 칸에 붙이고 위치를 변경할 수 있게 한다.
- 드래그와 함께 위치 선택 버튼을 제공한다. 영역 안에서 위치가 유지되고 스티커가 날짜 숫자와 선택 상태를 가리지 않게 한다.
- 붙일 수 있음, 붙임, 위치 편집 중, 저장 실패를 구분한다. 실패 시 편집 내용과 재시도 동작을 유지한다.
- 날짜 선택과 위치 변경을 터치, 키보드, 스크린리더로 완료할 수 있게 한다. 날짜 이동 중 선택된 날짜를 접근성 이름에 포함한다.

### 설정

- 프로필·목표, 알림설정, 언어, 표시 단위에 다시 접근할 수 있게 하고 현재 적용 상태를 표시한다.
- 언어는 시스템 기본과 개별 언어팩을 같은 목록에서 선택한다. 설정 진입 후 바로 찾을 수 있도록 언어 항목을 고정된 위치에 둔다.
- 목표 수정 시 적용되는 날짜와 과거 기록에 미치는 영향을 저장 전에 설명한다. 적용 범위는 도메인 계약을 따른다.

## 반응형 레이아웃과 접근성

- 휴대폰은 한 열로 배치하고 오늘의 기록 동작과 날짜 선택을 손쉽게 접근할 위치에 둔다. 작은 화면과 키보드 표시 중에도 주요 동작에 닿을 수 있게 한다.
- 태블릿은 가용 폭에 따라 달력과 날짜 상세, 오늘 요약과 기록 목록을 나란히 배치한다. 좁은 분할 화면에서는 한 열로 전환하고 탐색 상태를 유지한다.
- 화면 방향 전환, 안전 영역, 시스템 글자 크기 확대에서 목표량, 저장 동작, 안내 문구가 잘리지 않게 한다.
- 텍스트와 아이콘의 대비를 확인하고 진행·선택·보상 상태를 색, 형태, 텍스트로 전달한다. 터치 영역은 iOS 44pt, Android 48dp 이상을 목표로 한다.
- 컵 그림이 숫자 요약과 중복되면 접근성 트리에서 장식으로 처리한다. 기록 결과와 보상 갱신은 필요한 때 한 번씩 읽히게 한다.
- 동작 줄이기 설정에서는 물 차오름과 보상 전환을 정적 상태 변화로 표시한다. 화면 이동과 저장 후 포커스 복귀를 검증한다.

## 스티커 디자인과 상태

| 달성률 | 디자인 지침 |
|---|---|
| 100% 이상 | 가장 예쁘거나 귀여운 특별 캐릭터를 사용한다. 작은 크기에서도 실루엣과 포인트로 구분되게 한다. |
| 80% 이상, 100% 미만 | 귀여운 표정과 간결한 실루엣으로 100% 캐릭터와 구분한다. |
| 50% 이상, 80% 미만 | 엉뚱한 표정이나 살짝 삐뚤어진 형태로 살짝 못생긴 귀여움을 표현한다. 조롱이나 실패를 나타내는 표시를 피한다. |
| 50% 미만 | 스티커 없이 날짜와 기록을 보여준다. 상태 문구는 달성률이나 오늘 기록을 중립적으로 설명한다. |

- 100%를 넘겨도 같은 특별 스티커를 사용한다. 구간 판정은 도메인 값에 따르고 표시용 반올림으로 보상이 달라지지 않게 한다.
- 당일 표시에는 갱신 가능 상태를 명시한다. 날짜가 넘어가면 그날의 결과가 확정됐음을 달력 상세에서 확인할 수 있게 한다.
- 기록 수정·삭제, 목표 변경, 시간대 변경에 따른 결과는 도메인에서 전달받아 다시 표시한다. 화면은 재계산 중, 새 결과, 저장 실패를 구분한다.
- 상위 구간으로 바뀌거나 기록 정정으로 하위 구간이 되면 해당 날짜의 보상 안내와 이미지를 함께 갱신한다. 획득 조건을 벗어난 경우에는 현재 상태를 중립적으로 설명한다.
- 같은 날짜의 스티커가 교체됐을 때 위치를 보존하는 것을 초기 UI 제안으로 둔다. 보상이 사라졌다 돌아오는 경우의 위치 처리와 목표·시간대 정책은 S1에 도메인 계약으로 확정한다.
- 구간 경계, 날짜 전환, 붙이기 후 다시 실행, 기록 정정 이후의 UI를 수용 기준으로 삼는다.

## 언어·표시 형식

- 앱 내 언어팩은 `en`, `zh-Hans`, `zh-Hant`, `ja`, `ko`, `hi`를 기준으로 하며 선택값은 재시작 후 유지한다. 시스템 기본의 폴백은 현지화 담당과 합의한다.
- 초기설정, 화면 상태, 버튼, 예약 알림, 스티커 이름·설명, 접근성 문구를 지역화 리소스로 관리한다. 변경 후에 예약된 알림을 갱신하는 정책은 네이티브·현지화 담당과 합의한다.
- 언어는 문구에, 지역은 숫자·날짜 기본 형식에, 단위 설정은 용량 표시에 적용한다. 시간대와 시스템 12·24시간 선호를 반영한다.
- 내부 용량은 도메인의 mL 계약을 사용한다. 단위 전환을 제공할 경우 숫자와 단위를 함께 표시하고 반올림 후에도 선택한 양을 이해할 수 있게 한다.
- 문자열은 문장 단위로 지역화하고 줄바꿈과 확장을 허용한다. 달력의 요일, 좁은 버튼, 알림 액션은 각 언어와 큰 글자 크기에서 확인한다.
- 간체·번체·일본어·한국어별 글리프 폴백과 힌디어 데바나가리 결합 문자의 렌더링·줄 높이를 검증한다. 글꼴 선정 시 배포 권리와 오프라인 렌더링을 확인한다.
- 이미지에는 번역 문구, 숫자, 단위, 날짜를 넣지 않는다. 화면 텍스트를 이미지와 별개로 배치한다.

## 자산 제작과 출처

- 브랜드·캐릭터 방향이 결정되면 컵 채움 상태, 보상 구간별 스티커, 작은 날짜 칸 미리보기, 밝고 어두운 배경에서의 대비를 명세한다.
- 원본과 배포본의 자산 ID, 버전, 제작자, 출처, 라이선스와 상업 배포·수정 권한을 자산 목록에 남긴다. 생성 자산의 경우 사용 도구와 확인 가능한 사용 조건도 기록한다.
- 자산과 번역 키는 구간 ID에 대응시킨다. 달력과 오늘 화면에서 같은 원본을 쓰고 접근성 라벨은 현지화 리소스에서 불러온다.
- 자산의 표정, 형태, 제스처가 지원 시장에서 비하나 부정적 낙인으로 읽히는지 현지화 담당과 검토한다.

## 후속 파일 소유권

- UX·보상이 향후 화면 위젯, 공통 표시 컴포넌트, 스티커 배치 UI, 시각 자산과 자산 출처 목록을 소유한다. 실제 경로는 메인이 S1에 확정한다.
- 도메인 담당은 날짜별 판정·기록·스티커 위치 저장 계약을, 현지화 담당은 문자열·언어팩·표시 형식을, 네이티브 담당은 OS 알림과 액션 연결을 소유한다.
- 미정 사항은 브랜드와 캐릭터 스타일, 권장 목표의 근거·적용 범위, 표시 단위 옵션, 보상 재계산과 위치 복원 정책, OS별 알림 표현과 실기기 수용 범위다.
