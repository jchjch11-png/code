# 글로벌 물 마시기 앱 제품 요구사항

작성일: 2026-11-24. 이름 Hydration App은 작업용 명칭이며 출시 브랜드는 미정이다.

## 목표와 현재 범위

물 마실 시간을 알려주고, 알림에서 바로 섭취를 기록하며, 하루 달성률에 따라 받은 캐릭터 스티커를 앱 달력에 붙일 수 있는 글로벌 모바일 앱을 만든다.

대상은 아이폰, 아이패드, 안드로이드 휴대폰, 갤럭시탭이다. 현재 승인된 실행 범위는 팀 구성, Markdown 업무지침서 작성, 기존 GitHub 저장소 `jchjch11-png/code` 연결 및 문서 커밋·업로드다. 앱 구현·시험 배포·정식 출시는 후속 개발 단계다.

## 기능 요구사항

| ID | 요구사항 | 수용 기준 |
|---|---|---|
| P01 | 네 종류의 모바일·태블릿 기기 지원 | 실제 iPhone/iPad/Android phone/Galaxy Tab에서 주요 흐름을 검증하고 기기·OS를 기록한다. |
| P02 | 개인별 하루 목표 | 몸무게·성별·나이·활동량 등 입력란, 근거를 검토한 권장 목표 제안, 직접 목표 수정이 있다. 건강상 제한이 있으면 처방된 목표를 직접 입력할 수 있다. |
| P03 | 직관적인 섭취량 표시 | 컵 또는 캐릭터가 채워지는 그림과 현재량·목표량·남은 양·진행률을 함께 보여준다. 색상만으로 진행률을 전달하지 않는다. |
| P04 | 자동·수동 알림 | 기상·취침·조용한 시간을 반영해 자동 배치하거나 개별 시간을 지정한다. 목표와 회당 용량이 나누어떨어지지 않는 경우도 처리한다. |
| P05 | 알림에서 섭취 기록 | 해당 알림 예정량의 100%·50%를 기록하며 실제 mL도 표시한다. OS별 노출 방식에 맞춰 구현하고 중복 기록을 막는다. |
| P06 | 직접 기록·수정 | 자주 쓰는 컵 용량, 직접 섭취량 입력, 수정·삭제, 오입력 복구를 제공한다. |
| P07 | 미루기와 목표 달성 | 알림 미루기·건너뛰기, 목표 달성 후 그날 남은 알림 중단을 제공한다. 놓친 양을 단시간에 몰아서 권하지 않는다. |
| P08 | 단계별 보상 | 아래 보상 표에 맞게 날짜별 스티커를 제공하고 당일 성취 구간이 높아지면 갱신한다. |
| P09 | 스티커 달력 | 날짜별 섭취량·달성률·획득 스티커를 확인하고 해당 날짜 칸에 스티커를 붙이거나 위치를 조절한다. |
| P10 | 데이터 유지 | 앱 재시작 후 프로필·설정·기록·스티커가 유지된다. 날짜가 바뀌면 새 하루가 시작되고 전날 결과는 보존된다. |
| P11 | 언어 선택 | 설정에서 시스템 언어 또는 언어팩을 직접 선택한다. 첫 후보는 영어, 중국어 간체·번체, 일본어, 한국어, 힌디어다. |
| P12 | 지역별 표현 | 숫자·날짜·시간·단위·글꼴·텍스트 길이를 고려하고 선택 언어를 재시작 후에도 유지한다. 이미 예약한 알림도 언어 변경 정책에 따라 갱신한다. |

## 보상 규칙

| 하루 달성률 | 보상 |
|---|---|
| 100% 이상 | 가장 예쁘거나 귀여운 특별 스티커 |
| 80% 이상, 100% 미만 | 두 번째 등급의 귀여운 스티커 |
| 50% 이상, 80% 미만 | 엉뚱하고 살짝 못생긴 매력의 캐릭터 |
| 50% 미만 | 스티커 없음 |

초과 섭취 추가 보상은 없다. 당일에는 실시간으로 보상을 갱신하고, 날짜가 넘어가면 일별 결과를 확정한다. 기록 수정·목표 변경·시간대 변경 시 정합성은 도메인 문서에서 구체화한다.

## 초기 기술·제품 가정

- Flutter 공통 앱과 플랫폼별 알림 연동을 초기 기술안으로 한다. 패키지·버전은 알림 시제품 검증 후 선택한다.
- 첫 버전은 기기 내 저장과 로그인 없는 사용을 기본안으로 한다. 여러 기기 지원은 화면·OS 지원을 뜻하며 기기 간 기록 동기화를 뜻하지 않는다.
- 언어팩은 앱에 포함해 오프라인에서도 선택하게 한다. 초기 로캘은 `en`, `zh-Hans`, `zh-Hant`, `ja`, `ko`, `hi`다.
- 인도는 국가이며 단일 언어가 아니다. 첫 버전은 힌디어와 영어로 시작한다는 가정이다. 벵골어·타밀어·텔루구어 등은 수요에 따라 확장한다.
- 언어 지원과 국가별 스토어 출시는 별개다. 특히 중국어 지원이 중국 본토 Android 유통 지원을 자동으로 뜻하지 않는다. 초기 유통은 App Store·Google Play를 기준으로 계획한다.
- 계정 동기화, 건강 플랫폼 연동, 위젯, 광고·결제, 스티커 상점, 추가 Android 스토어 유통은 후속 범위다.

## 구현 전에 구체화할 결정

- 권장 목표 산정 근거, 적용 연령과 예외: 의학적 필수량으로 단정하지 않고 설명 가능한 음용 목표로 정한다.
- 최소 OS 버전, 알림 패키지, 플랫폼별 백그라운드 동작과 예약 제한: 실제 시제품 결과로 확정한다.
- 브랜드명과 캐릭터 스타일: 화면·자산 초안을 제시해 결정한다.
- 출시 국가, 개발자 계정, 서명 환경, 실기기 접근: 단계별 필요 시 확보한다.

## 제품 완료 조건

네 종류의 기기에서 목표 설정 → 알림 → 빠른 기록 → 보상 → 달력 확인이 동작하고, 지원 언어 선택과 데이터 유지가 검증되어야 한다. 정식 출시 완료는 두 스토어에 공개되고 설치·실행이 확인된 시점이다. 문서 작성이나 GitHub 업로드만으로 제품 출시 완료를 선언하지 않는다.
